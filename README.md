## 💬 Telegram 是什么

Telegram 是一款跨平台的即时通讯应用，主打端到端加密的私密聊天、群组、频道和文件传输。它由俄罗斯开发者 Pavel Durov 主导开发，2013 年上线，目前是用户规模排名靠前的通讯软件之一。

它的几个核心特性值得单独说：

- **云端消息** —— 消息历史同步在云端，换设备登录不丢聊天记录。
- **大文件传输** —— 支持最大 2GB 的单文件上传，适合传视频和安装包。
- **频道与群组** —— 广播频道和超大群组，是很多内容创作者和社区的阵地。
- **多端同步** —— 手机、电脑、网页版可以同时在线，消息实时同步。
- **端到端加密** —— 秘密聊天采用端到端加密，服务端无法读取内容。

正因为这些特性，Telegram 在国内用户群体里一直保持着稳定的使用热度。但也正因为它的跨境属性，注册和使用过程中会碰到国内环境特有的问题——验证码收不到、需要接码、地区限制、客户端下载渠道等。这些正是本站内容要覆盖的部分。
